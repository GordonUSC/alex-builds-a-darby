01

BEFORE YOU INSTALL

Check the basics.

Alex, start here. You don’t need to connect your inbox or messages to try this.

  • A Mac you control. Open Terminal with Spotlight: press Command + Space and type “Terminal.”
  • Node.js 24.16+ or 26.1+. The current guide recommends Node 26. Check your version below.
  • Model access. An existing Claude Code or Codex CLI login, or a provider API key. Availability and charges depend on your provider.
node --version

Ready when: you meet the runtime requirement and know which provider you’ll use. If Node is missing or older, follow the official Node guide first.

What will it cost?

Check the provider’s current pricing, usage limits, and billing before connecting it. A chat subscription and API billing are different arrangements; one does not automatically include the other. Set a spending limit where your provider supports it.

02

INSTALL & SIGN IN

Follow the current installer.

Use the official installation guide on your Mac. Review the installer before running it; it downloads and runs software. Onboarding follows installation. Choose your provider and read each permission request.

Ready when: onboarding has finished and you can identify the model account being used. If sign-in or billing is unclear, stop there.

Just want a temporary trial?

The official quickstart offers npx openclaw@latest. It downloads and runs OpenClaw; it is not a preview of this website. Its Gateway runs in that terminal until Control + C. A trial does not install the background service in the next step.

03

OPTIONAL FOR A TRIAL

Decide how it runs.

The Gateway connects your assistant to its tools and chat. To run it in the background after installation, stop the foreground Gateway with Control + C, then run:

openclaw gateway install

This creates a macOS LaunchAgent. If you’re only trying it for this session, leave the foreground Gateway running and skip this command.

Ready when: you’ve chosen a temporary session or a background service. Check the service instructions if your screen differs.

04

FIRST WORKING CHAT

Say hello.

With the Gateway running, check its status and open the browser dashboard:

openclaw gateway status
openclaw dashboard

In the chat, try: “Hello. What model am I using?”

Ready when: status shows the Gateway running and the chat returns a reply. If either fails, use the help section before adding anything else.

05

BEFORE CONNECTED ACCOUNTS

Choose its boundaries.

Start with sample text and draft-only work. Leave email, messaging, and sensitive accounts disconnected until you’ve reviewed their permissions.

An inbound allowlist is not an outbound send restriction. Message-tool access can allow sends across conversations and providers. Review account access, tool permissions, and outbound restrictions separately.

Read the security guide, then inspect the audit:

openclaw security audit

Ready when: you understand the access you’ve granted and have reviewed findings. A clean audit or a written “ask first” instruction is not a safety guarantee. Test behavior with harmless data.

06

YOUR NAME. YOUR WAY OF WORKING.

Make it yours.

Darby is Gordon’s assistant. Yours can have its own name and working style. Start with a short introduction you’re comfortable saving:

I’m Alex. Keep replies warm, direct, and practical. Put requirements and timing first. Separate confirmed facts from unknowns. Ask when information is missing. Draft things for my review; don’t make commitments on my behalf.

In the agent workspace, USER.md holds your preferences and IDENTITY.md holds the assistant’s identity. Review what gets saved. Keep credentials and private records out of this first exercise.

Ready when: you’ve checked its introduction and corrected anything it got wrong. Memory needs review, just like any other output.

07

THE FIRST USEFUL RESULT

Give it one small job.

Pick a starter below. Use the sample as written or replace it with non-sensitive details. The goal is a draft you can check.

SAMPLE DETAILS / DRAFT ONLY

Draft an event plan from these sample details: 12 guests, Thursday, a 2 p.m. arrival, and a 90-minute visit. Return an itinerary, a requirements checklist, and questions about missing information. The date, location, transport, and accessibility arrangements are unconfirmed. Do not invent them or contact anyone.

Look for: the supplied timing, a clear checklist, and questions about the missing details.

Check dates, numbers, missing details, and any commitments. Ask for a revision before you use it.

08

A GOOD PLACE TO PAUSE

Build from what worked.

For the first week, repeat one useful task. Note what needed correcting and adjust your instructions. There’s no need to connect everything at once.

When you’re ready for a phone channel

Choose one channel from the official channel guides and follow its specific setup. Review pairing and outbound permissions. Test with yourself first. Pairing and QR commands are not interchangeable setup instructions.

Ready when: you’ve chosen a task to repeat and know what access, if any, it actually needs.

SPURS UP, ALEX.

You’ve made a start.

A working assistant grows through useful tasks and your judgment. Keep the parts that help. Change the parts that don’t.

THE GARNET BOX

Stuck? Start
with what happened.

Keep the exact error and the step you reached. Remove keys, tokens, private messages, and personal details before sharing.

The dashboard won’t open

Check openclaw gateway status, then follow the official troubleshooting guide. Avoid exposing the dashboard publicly as a workaround.

I see a warning or error

Run openclaw doctor and read the findings. Automatic repair options change configuration; review the doctor documentation before using them.

Progress is stored only in this browser and can be lost when browser data is cleared. If storage is blocked, you can still read the guide. If copying fails, select the text and copy it manually. You can also print this page.
